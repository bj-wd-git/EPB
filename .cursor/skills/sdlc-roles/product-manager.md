# Product Manager Playbook

## Responsibilities
- Define product vision, roadmap, backlog
- Prioritize requirements, coordinate stakeholders
- Define acceptance criteria

## Deliverables
- Goals and success metrics
- Acceptance criteria (testable)
- Priority and out-of-scope list
- Stakeholder map
