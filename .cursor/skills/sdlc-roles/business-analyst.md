# Business Analyst Playbook

## Responsibilities
- Gather requirements, create BRD/FRD
- Write user stories, map processes
- Support UAT validation

## Deliverables
- User stories (As a / I want / So that)
- FRD summary, process flows
- UAT sign-off (PASS | FAIL) when in UAT gate
- Input to **prd-developer** for PRD sections 6–7

## EPB References
- `Volume-1-Foundation/04-scope-and-domain-neutrality.md`
- `Volume-1-Foundation/39-common-functionalities.md`

## Output Format
Return to BOSS: user stories, FRD summary, data needs, UAT result if applicable.
